# Java Spring

A collection of Spring Boot projects built while learning the Spring ecosystem. This repository demonstrates core backend development concepts, best practices, and commonly used Spring modules through small, focused applications.

## Topics Covered

- Spring Boot
- Spring MVC
- REST APIs
- Spring Data JPA
- Spring Security
- Spring HATEOAS
- H2 Database
- Maven
- Validation
- Exception Handling
- CRUD Operations

## Purpose

The goal of this repository is to practice backend development with Spring Boot by implementing different features and exploring how Spring components work together.

Each project focuses on a specific concept, making the repository a personal learning resource and reference for future development.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- Spring HATEOAS
- H2 Database
- Maven

## Getting Started

Clone the repository:

```bash
git clone https://github.com/isguliyev/java-spring.git
```

Navigate to any project and run:

```bash
./mvnw spring-boot:run
```

Or build the project:

```bash
./mvnw clean install
```

## Repository Structure

Each directory contains an independent Spring Boot project that explores a different concept or feature of the Spring framework.
